# Проверки после первой выкладки страниц заведений

Запускать после того, как Насим выложил первую пачку. `<slug>` — имя любой страницы из пачки, `<Название>` — название этого заведения.

| Что проверяем | Команда | Что должно быть |
|---|---|---|
| По адресу заведения открывается именно его страница, а не главная namax | `curl -s https://<slug>.namax.at/ \| grep -c "<Название>"` | `1` или больше |
| …и это не главная namax | `curl -s https://<slug>.namax.at/ \| grep -c "Studio für Web"` | `0` |
| Скрытая страница закрыта от поиска | `curl -s https://<slug>.namax.at/ \| grep -c noindex` | `1` у скрытой, `0` у открытой |
| Шрифты отдаются на адресе заведения | `curl -sI https://<slug>.namax.at/v/_shared/fonts/anton-latin.woff2` | `200` |
| Путь на основном сайте уводит на адрес заведения | `curl -sI https://www.namax.at/v/<slug>` | `307`, `location: https://<slug>.namax.at/` |
| Несуществующее заведение | `curl -sI https://gibt-es-nicht.namax.at/` | `404` |
| Основной сайт не задет | `curl -s https://www.namax.at/ \| grep -c "namax"` и `curl -sI https://www.namax.at/webdesign-wien` | больше `0` и `200` |
| Почта не задета | `nslookup -type=MX namax.at` | `mx03` и `mx04.secure-mailgate.com` |

## Что не проверено до выкладки

Адреса `<slug>.namax.at` обслуживает файл `middleware.js` в корне проекта: он срабатывает раньше, чем Vercel ищет файл, и подставляет папку `/v/<slug>/`. Без него по адресу заведения открылась бы главная страница namax. Проверить это можно только на настоящем домене. Локально то же поведение имитирует `tools/serve.mjs` на адресах `<slug>.localhost:4173`.

Не проверено на Vercel:
- что `middleware.js` вообще подхватывается в проекте без `package.json`;
- что подстановка адреса не вызывает перенаправление на `/v/<slug>`;
- что имя заведения подставляется в адрес перенаправления с `www.namax.at/v/<slug>`.

Если первая строка таблицы даёт `0`:
1. Проверить, что сертификат для `*.namax.at` выпущен (Vercel → проект → Domains).
2. Посмотреть в Vercel → проект → Logs, вызывается ли Middleware на запрос к адресу заведения.
3. Не выкладывать пачку дальше, пока это не починено: по адресам заведений будет открываться главная namax.
